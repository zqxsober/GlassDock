# GlassDock v0.0.2

## 中文

本版本加入可选的首次启动引导，帮助用户了解 GlassDock 的权限和连接方式：

- 辅助功能：读取窗口标题，并切换或关闭指定窗口。
- 日历与提醒事项：连接对应组件后显示日程或提醒。
- 自动化（音乐）：读取 Apple“音乐”App 的播放信息并控制播放。
- Codex：说明如何连接已登录的 Codex CLI 以读取账户额度。

所有权限均为可选。选择“稍后再说”或“完成”都会保存引导已完成状态。已有配置的 v0.0.1 用户升级时会静默标记为已完成，不会自动弹出；之后可从偏好设置或菜单栏的“重新打开引导”入口手动打开。引导和重新打开入口支持中文、英文；这项语言支持仅覆盖引导及其入口，不表示应用其他界面已全面双语化。

README 中的图片和说明用于帮助理解现有界面，属于文档内容，不代表新增应用功能。

验证：完整测试 148 项通过、1 项因环境限制跳过，无失败。DMG 已只读挂载核对版本、双架构、许可证及签名完整性，SHA-256 校验通过。通用包包含 arm64 和 x86_64；Intel 尚未进行真机运行验证，本次也未单独进行系统权限弹窗的交互式验收。

### 下载与安装

下载 `GlassDock-v0.0.2-universal.dmg`，将 `GlassDock.app` 拖入“应用程序”文件夹。通用包包含 Apple 芯片 `arm64` 和 Intel `x86_64` 二进制，要求 macOS 26 或更高版本。Intel 架构为交叉编译，尚未在 Intel 真机上验证。

**本版本使用 ad-hoc 临时签名，未经 Apple 公证。** Gatekeeper 可能在首次打开时警告或阻止应用。请先确认下载来源，再按系统提示在“系统设置 → 隐私与安全性”中决定是否允许打开；无需全局关闭 Gatekeeper。

发布页提供 SHA-256 校验文件。将 DMG 与对应的 `.sha256` 文件放在同一目录后执行：

```bash
shasum -a 256 -c GlassDock-v0.0.2-universal.dmg.sha256
```

### 权限提示

- 辅助功能权限可能无法在 ad-hoc 更新后沿用。如果窗口操作失效，请在系统设置中移除旧的 GlassDock 授权，再为当前安装的应用重新开启。
- 日历、提醒事项和音乐自动化权限按需授予；拒绝或稍后处理不会影响其他 Dock 功能。
- Codex 额度信息需要已安装并登录的 Codex CLI；引导只提供连接说明，不要求输入 API Key。

## English

This release adds an optional first-launch guide to explain GlassDock permissions and connections:

- **Accessibility**: Read window titles and switch to or close a specific window.
- **Calendar and Reminders**: Show events or reminders after connecting the corresponding widget.
- **Automation (Music)**: Read now-playing information from the macOS Music app and control playback.
- **Codex**: Learn how to connect a signed-in Codex CLI to read account usage.

Every permission is optional. Both **Not Now** and **Done** save the guide as completed. Existing v0.0.1 users with saved preferences are marked complete silently during upgrade, so the guide does not open automatically. They can reopen it from Settings or the menu bar. The guide and its reopen entry are available in Chinese and English; this language support applies only to those surfaces and does not localize the rest of the app.

README images and captions document the existing interface; they do not represent new in-app features.

Validation: 148 tests passed, 1 skipped due to an environment limitation, and no failures. The DMG was mounted read-only to verify its version, universal architectures, license files, and signature integrity; its SHA-256 checksum passed. The package contains arm64 and x86_64. Intel hardware execution and interactive system permission prompts were not separately verified in this run.

### Download and install

Download `GlassDock-v0.0.2-universal.dmg` and drag `GlassDock.app` into Applications. The universal package includes `arm64` for Apple silicon and `x86_64` for Intel, and requires macOS 26 or later. The Intel binary is cross-compiled and has not been tested on Intel hardware.

**This release is ad-hoc signed and has not been notarized by Apple.** Gatekeeper may warn about or block the app on first launch. Confirm the download source, then follow the macOS guidance in **System Settings → Privacy & Security** to decide whether to allow it. Do not disable Gatekeeper globally.

The release page provides a SHA-256 checksum file. With the DMG and its `.sha256` file in the same directory, verify the download with:

```bash
shasum -a 256 -c GlassDock-v0.0.2-universal.dmg.sha256
```

### Permission notes

- macOS may not retain Accessibility authorization after an ad-hoc update. If window actions stop working, remove the old GlassDock entry in System Settings and enable access for the currently installed app.
- Grant Calendar, Reminders, and Music automation access only as needed. Declining or postponing access does not affect other Dock features.
- Codex usage requires Codex CLI to be installed and signed in. The guide explains the connection and does not ask for an API key.
