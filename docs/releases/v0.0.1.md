# GlassDock v0.0.1

## 中文

GlassDock 首次开源发布：适用于 macOS 26 及以上版本的原生 Liquid Glass 悬浮 Dock，使用 Apache License 2.0。

- 应用和文件夹固定、拖动排序、悬停放大、键盘导航及可调整尺寸。
- 多窗口独立入口，点击切换到指定窗口，右键关闭单个窗口。
- 35 种可选小组件样式，涵盖时钟、计时、日历、提醒事项、便签、音乐、系统状态与 AI 额度等。
- Codex 真实账户额度：5 小时 / 7 天剩余额度及重置倒计时，支持数字、圆环、条形和双胶囊样式。
- 中文和英文 README，附带许可证、NOTICE 和可复用构建 / 打包脚本。

### 下载与安装

下载 `GlassDock-v0.0.1-universal.dmg`，将 `GlassDock.app` 拖入“应用程序”文件夹。通用包包含 Apple 芯片 arm64 和 Intel x86_64 二进制，要求 macOS 26+。

**本版本使用 ad-hoc 临时签名，未经过 Apple 公证。** 首次启动可能被 Gatekeeper 阻止，请按系统提示在“系统设置 → 隐私与安全性”中决定是否允许打开。

SHA-256 校验文件与构建信息随安装包提供。下载到同一目录后可执行：

```bash
shasum -a 256 -c GlassDock-v0.0.1-universal.dmg.sha256
```

### 使用条件与验证

- 窗口管理需要辅助功能权限；日历、提醒事项和音乐控制按需请求对应权限。
- AI 额度需要已安装并以 ChatGPT 账户登录的 Codex CLI；额度读取不发起模型推理。
- 天气组件目前为待配置占位，尚无实时天气数据。
- 完整测试：135 项通过、1 项因环境限制跳过；安装包、通用架构、签名完整性和 SHA-256 已验证。
- Intel 架构已交叉编译，尚未进行 Intel 真机运行验证。

## English

The first open-source release of GlassDock, a native Liquid Glass floating Dock for macOS 26+, licensed under Apache License 2.0.

- Pin apps and folders, reorder by dragging, hover magnification, keyboard navigation, and adjustable sizing.
- Separate entries for app windows, activation of a selected window, and a context-menu action to close that window.
- 35 selectable widget styles covering clocks, timers, calendars, reminders, notes, music, system status, AI usage, and more.
- Live Codex account limits: remaining 5-hour / 7-day allowances and reset countdowns, with numeric, ring, bar, and dual-capsule styles.
- Chinese and English READMEs, license and NOTICE files, and reusable build / packaging scripts.

### Download and install

Download `GlassDock-v0.0.1-universal.dmg` and drag `GlassDock.app` into Applications. The universal app includes arm64 for Apple silicon and x86_64 for Intel, and requires macOS 26+.

**This release is ad-hoc signed and has not been notarized by Apple.** Gatekeeper may block its first launch. Follow the system guidance in System Settings → Privacy & Security to decide whether to allow it.

A SHA-256 checksum file and build information are included as release assets. With the DMG and checksum in the same directory, run the command above to verify the download.

### Requirements and validation

- Window management needs Accessibility permission. Calendar, Reminders, and Music automation permissions are requested as needed.
- AI usage requires Codex CLI installed and signed in with a ChatGPT account. Reading limits does not initiate model inference.
- Weather widgets are placeholders without live weather data.
- Full test suite: 135 passed and 1 skipped due to an environment limitation. Package contents, universal architectures, signature integrity, and SHA-256 were verified.
- The Intel binary was cross-compiled; it has not been tested on Intel hardware.
